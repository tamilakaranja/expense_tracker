# Expense Tracker

A simple and user-friendly expense tracker built with HTML, CSS, and JavaScript. This project helps users record their daily expenses, organise spending by category, and keep track of their total expenses.

## Live Demo

[View Expense Tracker](https://tamilakaranja.github.io/expense_tracker/)

## Features

- **Add Expenses:** Record an expense using its description, amount, and category.
- **View Expenses:** Display recorded expenses in a list.
- **Delete Expenses:** Remove expenses that are no longer needed.
- **Expense Total:** Automatically calculate the total amount spent.
- **Filter by Category:** View expenses belonging to a selected category.
- **Local Storage:** Save expenses in the browser so they remain available after refreshing the page.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## How to Use

1. Open the [Expense Tracker](https://tamilakaranja.github.io/expense_tracker/).
2. Enter an expense description.
3. Enter the amount spent.
4. Select an expense category.
5. Click **Add Expense**.
6. View your expenses and automatically updated total.
7. Use the category filter to organise your expenses.
8. Click **Delete** to remove an expense.

Your expenses remain saved in your browser through Local Storage.
